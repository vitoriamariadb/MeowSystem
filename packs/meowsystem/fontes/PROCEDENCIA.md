# Procedência da fonte do terminal

`JetBrainsMono.tar.xz` é a fonte monoespaçada que o instalador põe no terminal e na interface
(`JetBrainsMono Nerd Font Mono`). O instalador (`scripts/instalar_fontes.sh`) extrai as 16 faces
direto deste arquivo, confere o sha256 de cada uma e não baixa nada.

| campo | valor |
|---|---|
| origem | <https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.0/JetBrainsMono.tar.xz> |
| release | `v3.5.0` do ryanoasis/nerd-fonts |
| sha256 | `0227b220360a6f819b9ead92343e8112b34733054782561af50cfba1e8afab63` |
| tamanho | 6371912 bytes |
| licença | OFL-1.1 (a fonte JetBrains Mono) e MIT (o patcher do Nerd Fonts); o texto da OFL vai dentro do próprio `.tar.xz` |
| baixado em | 2026-09 (o mesmo arquivo que o instalador baixava e conferia; conferido de novo em 2026-10-26) |
