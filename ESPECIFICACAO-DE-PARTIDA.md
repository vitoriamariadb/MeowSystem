## Contrato de idempotência (a regra que rege tudo)

Toda unidade de trabalho é um par **`checar` + `aplicar`**. Sem exceção.

```bash
meow::tema::checar()    # 0 = já está como deveria | 1 = divergente (imprime o diff)
meow::tema::aplicar()   # leva do estado atual ao desejado; roda só se checar()==1
meow::tema::desfazer()  # restaura o backup mais recente dessa unidade
```

Cada módulo (`tema`, `logo`, `icones`, `wallpaper`, `fastfetch`, `zsh`, `apps/*`)
implementa os três. Disso saem de graça: `meow doctor` (roda todos os `checar`),
`meow aplicar` (roda só os que falharam), o timer de auto-reparo e o `--dry-run`.

Regras duras:

1. **Estado desejado é declarado, não imperativo.** Tudo que define "como deve
   ficar" vive em `meow.conf` + `palette/` + `mapping.json`. Script não guarda
   decisão no corpo.
2. **Escrita atômica.** Nunca `>` direto no arquivo final, nunca `>>`. Sempre
   `tmp` no **mesmo diretório de destino** (`/mnt/Apate` e `$HOME` são sistemas
   de arquivos diferentes — `mv` entre eles não é atômico) e depois `mv`.
3. **Nada de append em lista.** Ao mexer em `plugins_wings`, `favorites`,
   `.zshrc` etc., reescreva o valor inteiro a partir do estado desejado. Rodar
   duas vezes não pode duplicar item.
4. **Backup antes de escrever**, sempre: `~/.local/state/meowsystem/backups/<ISO>/`
   com `manifesto.sha256`, retendo as 10 últimas. `meow desfazer` restaura a
   última; `meow desfazer <timestamp>` restaura uma específica.
5. **Comparação por conteúdo, não por existência.** `checar` compara sha256 do
   que está no disco com o que seria gerado. Se igual, não escreve, não faz
   backup, não loga ruído.
6. **`--dry-run` em toda subcomando**, mostrando o diff colorido do que mudaria.
7. **Exit codes honestos:** 0 ok · 1 divergência · 2 erro de execução ·
   3 dependência faltando. O timer só grita quando é 2 ou 3.
8. **Falha por unidade, não global.** Obsidian ausente não pode abortar o resto;
   entra como `pulado` no relatório final.
9. **Nada em `/usr/share`.** Só `~/.local/share`, `~/.config`, `~/.local/state`.
   `sudo` apenas para `apt install papirus-icon-theme` e para o hook do APT —
   sempre perguntando antes.
10. **Reentrante sob concorrência:** lockfile em `~/.local/state/meowsystem/lock`
    (o timer pode disparar enquanto ela roda na mão).

## Qualidade de vida — a CLI `meow`

Instalada em `~/.local/bin/meow`, com completions de zsh. É a interface principal;
`install.sh` é só o bootstrap que a instala.

```
meow status                   # painel de estado: flavor, accent, ícones, wallpaper atual,
                              # último reparo, o que está divergente — com as cores no terminal
meow doctor                   # roda todos os checar(); lista divergências e o que fazer
meow doctor --consertar       # = doctor + aplicar só o que falhou

meow tema                     # mostra o tema ativo
meow tema mocha-pink          # troca flavor/accent (tab-completa os disponíveis)
meow tema claro | escuro | auto   # alterna Mode/is_dark, ou horário automático
meow tema capturar <nome>     # captura o estado atual como tema nomeado
meow tema desfazer

meow logo                     # lista as variantes disponíveis em assets/
meow logo mocha               # troca a logo do painel + do dock de uma vez
meow logo <caminho.svg>       # usa um SVG seu (valida antes: viewBox, tamanho, cores)

meow icones                   # estado do tema de ícones
meow icones reconstruir       # rebuild + cache + relatório de apps sem ícone próprio

meow wallpaper                # ver §carrossel
meow apps                     # tabela: app instalado × tema aplicado × pendente
meow apps aplicar <slug>

meow atualizar                # git pull + rebuild + aplicar só o que mudou
meow desfazer                 # rollback do último aplicar
meow log                      # últimas 50 linhas, colorido
```

Mais QoL, obrigatório:

- **Menu FZF** no mesmo padrão do `conjurar.zsh` do Andromeda-OS: `meow` sem
  argumento abre o menu interativo. Registre também uma entrada no `conjurar`.
- **Notificação** (`notify-send`) ao trocar tema/wallpaper e quando o auto-reparo
  consertar algo sozinho — ela precisa saber que aconteceu.
- **Um arquivo pra editar tudo**: `meow.conf` (formato `CHAVE=valor`, comentado
  em pt-BR) com `FLAVOR`, `ACCENT`, `LOGO`, `ICONES_BASE`, `WALLPAPER_DIR`,
  `WALLPAPER_INTERVALO`, `WALLPAPER_ORDEM`, `APPS_ATIVOS`, `AUTO_REPARO`.
  Trocar qualquer coisa = editar uma linha e rodar `meow aplicar`.
- **README com receitas de 1 linha**: como trocar de flavor, adicionar um
  wallpaper, curar o ícone de um app, adicionar um app novo ao catálogo,
  desfazer tudo. Cada uma cabendo numa linha de comando.
- **Mensagens em pt-BR**, com as cores da paleta, ícone de status
  (`ok` / `divergente` / `pulado`), e sempre dizendo **o que fazer a seguir**.
- **Zero pergunta em modo automático** (`--yes`), TUI whiptail no interativo
  (mesmo padrão do `install.sh` do Andromeda-OS).

## Carrossel de wallpaper

É funcionalidade de primeira classe, não um `cp` numa pasta.

**Pastas**

```
~/.local/share/backgrounds/meowsystem/
├── ativos/       # o que entra na rotação  ← source: Path(essa pasta)
├── favoritos/    # nunca sai da rotação
├── banidos/      # saiu por decisão dela (não apagar, mover)
└── originais/    # a foto antes da recolorização (pra poder refazer)
```

**Comandos**

```
meow wallpaper                      # qual está agora + quanto falta pro próximo
meow wallpaper proximo              # força o próximo já
meow wallpaper fixar                # pausa a rotação no atual
meow wallpaper favoritar            # move o atual pra favoritos/
meow wallpaper banir                # move o atual pra banidos/ e pula
meow wallpaper intervalo 10m        # aceita 30s / 10m / 2h
meow wallpaper ordem aleatoria|alfabetica
meow wallpaper adicionar <img|url|pasta>
meow wallpaper recolorir <img>      # lutgen → paleta do flavor ativo → ativos/
meow wallpaper semear               # baixa a coleção da comunidade (commit pinado)
```

**Implementação**

- Base é a rotação **nativa**: `CosmicBackground/v1/all` com
  `source: Path("<ativos>")`, `rotation_frequency: <segundos>`,
  `sampling_method: Random|Alphanumeric`. Preserve `filter_method: Lanczos` e
  `scaling_mode: Fit((0.0, 0.0, 0.0))` — são as escolhas dela.
- `same-on-all: true` está ligado, mas existem `output.DP-1` e `output.HDMI-A-1`.
  Escreva os três de forma **consistente** e trate monitor desconectado sem erro.
- `proximo` / `fixar` precisam funcionar de verdade: investigue se o `cosmic-bg`
  expõe algum gatilho; se não expuser, implemente a rotação nós mesmos com um
  `systemd --user` timer que reescreve `source` com um arquivo sorteado, e
  desligue a rotação nativa (`rotation_frequency` alto) pra não brigarem.
  **Documente qual dos dois caminhos foi usado e por quê.**
- Sementes: `zhichaoh/catppuccin-wallpapers` (commit **pinado**, nunca `main`
  solto), `pop-os/cosmic-wallpapers` e as fotos dela recoloridas. As imagens
  **não vão pro git** — o repo guarda a lista e o script que baixa/gera.
- Registre no log qual imagem entrou e quando; `meow status` mostra o nome.

## O que NÃO fazer

- Não criar tema GTK nem tocar em CSS de shell — não existe no COSMIC.
- Não portar as 14 extensões GNOME do Dracula_OS-Theme.
- Não usar `xwinwrap`/`mpv` pra wallpaper de vídeo — é X11, não roda no Wayland.
- Não prometer ícone animado no painel via SVG (§4.8 do relatório).
- Não editar `/usr/share/icons/Papirus` — quebra no `apt upgrade`.
- Não mexer nas listas `plugins_center`/`plugins_wings` do painel e do dock: são
  a planta dela (LogoMenu, Battery, brightness, Workspaces | Notifications, Time |
  StatusArea, Drives, clipboard, Bluetooth, Tiling, Audio, Network, Power).
- Não mexer nos atalhos de teclado — são do `Andromeda-OS`.
- Não commitar imagens/wallpapers.
- Não inventar caminho, chave, flag ou nome de repositório. Verifique; se não
  der, marque `TODO(verificar)` e pergunte.
